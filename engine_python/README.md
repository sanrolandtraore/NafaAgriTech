# NAFA AGRITECH — Moteur Scientifique & Ingénierie Python

Noyau de calcul d'ingénierie agronomique, vétérinaire, modélisation 2D/3D et vision par ordinateur.

## Modules :
- `nafa.crops_vision` : Vision par ordinateur pour la santé des cultures (NDVI, VARI, GLI, détection de chlorose, nécrose, Spodoptera frugiperda)
- `nafa.livestock_density` : Zootechnie vétérinaire, comptage automatisé, UBT, stress thermique THI
- `nafa.modeling_2d_3d` : Modélisation géométrique 2D (SIG/Shapely) et 3D (Wavefront OBJ, bioclimatisme)
- `nafa.field_suite` : Arpentage GPS (UTM 30N/31N), besoins en eau FAO-56, hydraulique Hazen-Williams / Christiansen, devis BPU FCFA et rapports de terrain
- `nafa.api` : Serveur FastAPI REST pour intégration web et mobile
- `nafa.cli` : Outil en ligne de commande pour exécution autonome
